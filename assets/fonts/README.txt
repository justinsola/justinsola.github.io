Source Serif 4 — locally hosted variable web fonts

Roman and italic retain weight 200–900 and optical size 8–60.
Subset from the official Google Fonts distribution to Latin, Latin Extended-A,
combining accents, punctuation, superscripts/subscripts, currencies, and
available presentation ligatures. Other scripts use the site fallback font.
All visible characters on the current four main pages are included.

Font files use the SIL OFL; see SourceSerif4-OFL.txt.
Upstream: https://github.com/google/fonts/tree/main/ofl/sourceserif4
Shared CSS defines the font; the layout preloads both faces.
